# Learn with Joon

A responsive tutoring website by Peng Hung Joon, developed with ChatGPT assistance.

Features include three interactive mini lessons, answer feedback and hints, mobile navigation, subject information, and a demonstration enquiry form.

## Portfolio version

This GitHub Pages version preserves the original design and lessons. The enquiry form is a clearly labelled demo: it does not store or send submissions. The original server-side private inbox is not included.

## Local development

```sh
npm ci
npm run dev
```

Build with `npm run build`. The `dist` directory contains the deployable website.

## Publishing

In repository Settings → Pages, choose Deploy from a branch, branch `main`, folder `/docs`, then Save.

Expected address after publication: https://hungjooncoding.github.io/learn-with-joon/
